meta-w77q-pkcs11 (Main Layer)

This is where all Winbond-specific code lives. It patches OP-TEE to replace the default storage backend with W77Q/T secure flash.

PathPurpose
build.shBuild orchestrator — wraps upstream BSP build, injects all layers
recipes-bsp/qlib/qlib-bin_git.bbFetches prebuilt libqlib.a (aarch64) + public API headers from qlib-bin at build time
conf/Yocto layer configuration + build templates
recipes-bsp/optee/optee-os_%.bbappendEntry point: patches OP-TEE, enables CFG_W77Q_FS=y, and fetches pinned upstream LittleFS sources
recipes-bsp/optee/files/*.patchOP-TEE patches (SPI driver, W77Q/T driver, FS backend, QLIB wiring, PTAs)
recipes-bsp/optee/files/qlib-tee/QLIB ↔ OP-TEE glue: qlib_platform.c, w77q_qlib.c, sub.mk
recipes-bsp/optee/files/layer2_storage/LittleFS backend: tee_lfs_storage.c, tee_lfs_storage.h, w77q_lfs_port.c, w77q_lfs_port.h, lfs_w77q_cfg.h
recipes-bsp/w77q-provision/Normal-world provisioning CLI tool
recipes-examples/pkcs11-app/PKCS#11 demo application
recipes-examples/tee-storage/TEE persistent storage demo
recipes-dev/Development TAs (tee-demo, tee-storage-test)
recipes-utils/pkcs11-tests/Automated PKCS#11 test suite
tests/Host-side Python test scripts
scripts/Utility scripts (deploy, test runners)
docs/Design documents, data-flow diagrams, flash maps

Hardware enablement layer for the Sparrow Hawk board's secure boot chain.

External Dependency (Not Included)

meta-sparrow-hawk — the upstream community BSP — must be cloned separately. See the Build Guide for instructions.
littlefs — open-source filesystem library — is fetched automatically from GitHub during build by optee-os_%.bbappend at a pinned commit.
