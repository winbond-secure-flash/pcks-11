Release Notes

Version 0.1.0 (August 2026)

ALPHA RELEASE — This is a pre-production technology preview. APIs, flash layout, and provisioning flows may change without notice.

Overview

First alpha release of the W77Q/T PKCS#11 secure storage solution for the Renesas R-Car V4H Sparrow Hawk platform. This release demonstrates end-to-end key generation, storage, and cryptographic operations backed by Winbond W77Q/T secure NOR flash via OP-TEE.

Features

  • PKCS#11 token operations via OP-TEE PKCS#11 TA with W77Q/T backend storage
  • RSA-2048/4096, EC P-256/P-384, AES-128/256, HMAC key generation and storage
  • Sign, verify, encrypt, decrypt operations through standard PKCS#11 interface
  • Persistent key storage on W77Q/T flash (survives reboot)
  • QLIB authenticated session protocol for data-at-rest protection
  • SPI RPC-IF driver for R-Car V4H ↔ W77Q/T communication
  • LIFEC hardware lockdown (SPI accessible only from Secure World)
  • Yocto/OE (scarthgap) build system with single-command build
  • Installation verification script (verify-install.sh)
  • Host-side and on-board integration test suite

Known Limitations

  1. Development keys only — Sample keys are used for demonstration purposes. Keys must be replaced with unique production keys to achieve security.
  2. LittleFS geometry lock-in — PKCS#11 data is tied to the configured LittleFS geometry. If W77Q_LFS_BLOCK_SIZE or related layout parameters are changed, the storage area must be reformatted before reuse.
  3. Section 1 sized to 16 MB — 16 MB of W77Q/T Section 1 is currently mapped for PKCS#11 storage.
  4. No secure boot chain validation — BL2→BL31→OP-TEE chain of trust is not enforced in this alpha (development mode).
  5. Single-board target — Only the Sparrow Hawk (R-Car V4H) board is supported.
