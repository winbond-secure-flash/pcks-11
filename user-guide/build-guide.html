Build Guide

1. Host Prerequisites

A Linux build host is required (Ubuntu 22.04 or 24.04 recommended).

Ubuntu 22.04:

sudo apt update && sudo apt install -y \
    gawk wget git diffstat unzip texinfo gcc build-essential \
    chrpath socat cpio python3 python3-pip python3-pexpect \
    xz-utils debianutils iputils-ping python3-git python3-jinja2 \
    libegl1-mesa libsdl1.2-dev pylint xterm python3-subunit \
    mesa-common-dev zstd liblz4-tool file bmap-tools \
    picocom screen libssl-dev

Ubuntu 24.04:

sudo apt update && sudo apt install -y \
    gawk wget git diffstat unzip texinfo gcc build-essential \
    chrpath socat cpio python3 python3-pip python3-pexpect \
    xz-utils debianutils iputils-ping python3-git python3-jinja2 \
    libegl-dev libsdl1.2-dev pylint xterm python3-subunit \
    mesa-common-dev zstd liblz4-tool file bmap-tools \
    picocom screen libssl-dev

Requirements:

  • Disk space: ~100 GB free
  • RAM: 16 GB+ recommended
  • CPU: 8+ cores recommended (Yocto is heavily parallelized)
No separate Yocto installation needed. The build system (Poky/OpenEmbedded) is automatically cloned by build.sh on the first run if not already present. The apt packages listed above are the only manual host setup required.

2. Clone External Dependencies

The upstream BSP layer is not included in this release. You must clone it yourself. Poky and meta-openembedded are fetched automatically by build.sh on the first run. 
# From the release root directory:
git clone --branch scarthgap \
    https://github.com/rcar-community/meta-sparrow-hawk.git \
    imports/meta-sparrow-hawk

4. Build

bash build.sh
Expected output (last lines on success): 
NOTE: Tasks Summary: Attempted 4521 tasks of which 4300 didn't need to be rerun and all succeeded.

=== Build complete ===
Output artifacts copied to: meta-w77q-pkcs11/output_pkcs11/

The build script performs these steps:

  1. Validates that all sibling repositories are present
  2. Creates symlinks in the Yocto build workspace
  3. Injects meta-w77q-pkcs11's template (adds all layers to bblayers.conf)
  4. Invokes the upstream BSP build.sh (which sources oe-init-build-env)
  5. Copies output artifacts to meta-w77q-pkcs11/output_pkcs11/

Build Options

OptionEffect
./build.sh --westonInclude Weston graphics stack (GPU/display support)

First Build Time

The first build downloads all sources and compiles from scratch — expect 1–3 hours depending on host CPU and internet speed. Subsequent builds use Yocto's shared-state cache and complete in 15–30 minutes.

5. WSL Note

When running under Windows Subsystem for Linux on a /mnt/ path, the build directory is automatically redirected to $HOME/yocto-sparrow-hawk to avoid NTFS performance issues. A symlink is created at the expected location.

6. Build Outputs

After a successful build, artifacts are in meta-w77q-pkcs11/output_pkcs11/:

7. Rebuilding Individual Recipes

After the initial build, you can rebuild specific components without a full rebuild:

# Enter the Yocto build environment
source imports/meta-sparrow-hawk/build/build-sparrow-hawk/conf/../../poky/oe-init-build-env \
    imports/meta-sparrow-hawk/build/build-sparrow-hawk

# Rebuild OP-TEE OS only (after W77Q/T code changes)
bitbake optee-os -c cleansstate && bitbake optee-os

# Rebuild the full image
bitbake core-image-minimal
