CVE Disclaimer

Note: This is an alpha release provided for evaluation purposes. Security hardening is ongoing. One known critical issue (CVE-2025-10263, Arm TLBI errata) remains open and requires SoC-vendor coordination to resolve.
DISCLAIMER: This release package is provided as a reference sample. Winbond has performed CVE cleanup of its source code as described below. Winbond does not accept responsibility for any vulnerabilities discovered after the CVE cleanup date. It is the customer's (integrator's) responsibility to perform their own security assessment and to track, mitigate, and patch any CVEs that may be disclosed in the future — both in Winbond-provided sample code and in all third-party components integrated into the final product.

CVE cleanup date: 2026-07-12

Scanning Methodology

The following methods were used to identify and resolve known CVEs in the Winbond-authored source code:

  1. Yocto CVE Check (cve-check class): The Yocto build system's built-in CVE scanner was executed against all recipes in the image. This tool cross-references each package version against the NIST NVD database and generates per-recipe CVE status reports. 
    INHERIT += "cve-check"
  2. Static Analysis / SAST: Winbond-authored C source code was scanned using static analysis tools to identify potential memory safety issues (buffer overflows, out-of-bounds access, use-after-free) and other CWE patterns commonly associated with PKCS#11 ecosystem vulnerabilities.
  3. NVD / GitHub Advisory Database Review: Manual review of the NIST National Vulnerability Database and GitHub Security Advisories (GHSA) for all components and their pinned versions included in this release, specifically targeting:
    • OP-TEE PKCS#11 TA advisories
    • OpenSC / libckteec advisories
    • openCryptoki advisories
    • GnuTLS PKCS#11-related advisories
  4. Dependency Version Audit: All pinned third-party component versions were checked against their respective upstream security advisories and changelogs to confirm no unpatched CVEs exist at the time of cleanup.
