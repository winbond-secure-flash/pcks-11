Flash & Boot

1. Prerequisites

Use the canonical host setup from Build Guide → Host Prerequisites. This page assumes those tools are already installed.

2. Write SD Card

The WIC image contains the full root filesystem, kernel (fitImage), and device tree.

Identify the SD card device:

lsblk

Look for the SD card by its size (e.g., /dev/sde).

Using bmaptool (recommended — fast, sparse-aware)

sudo bmaptool copy \
    meta-w77q-pkcs11/output_pkcs11/core-image-minimal-sparrow-hawk.rootfs.wic.gz \
    /dev/sdX
Expected output: 
bmaptool: info: block map format version 2.0
bmaptool: info: 1234567 blocks of size 4096 (4.7 GiB), mapped 512345 blocks (2.0 GiB or 41.5%)
bmaptool: info: copying image ... done

Using dd (fallback)

zcat meta-w77q-pkcs11/output_pkcs11/core-image-minimal-sparrow-hawk.rootfs.wic.gz | \
    sudo dd of=/dev/sdX bs=4M status=progress
sync
Expected output: 
4831838208 bytes (4.8 GB, 4.5 GiB) copied, 312 s, 15.5 MB/s
1152+1 records in
1152+1 records out
Replace /dev/sdX with your actual SD card device. Double-check with lsblk before writing — this will overwrite all data on the target device.

3. Flash SPI NOR (Boot Firmware)

The flash.bin image contains BL2 + BL31 (with RPC-IF init) + OP-TEE + U-Boot. It must be written to the board's SPI NOR flash.

Step-by-step procedure

  1. Ensure the board is in normal boot mode — DIP-switch pins 1-3 set to ON.
  2. Connect the USB serial cable (USB-Micro USB) between the host PC and the board.
  3. Power on the board (or leave it powered — the script handles both cases).
  4. Run the flash script:

Using the deploy script

The script catches U-Boot autoboot, loads flash.bin via Y-Modem, and writes it to SPI NOR:

sudo python3 w77q_renesas_rcar_v4h_bsp/scripts/deploy-flash-bin.py \
    --flash meta-w77q-pkcs11/output_pkcs11/flash.bin \
    --port /dev/ttyUSB0
Make sure --port points to the correct serial device. Use ls /dev/ttyUSB* to list available ports. In most setups the board console is /dev/ttyUSB0.
Expected output: 
[ ok  ] OP-TEE driver initialized — flash successful!
[ ok  ] deploy-flash-bin complete.

4. Serial Console

Connect the board serial port using a USB-Micro USB cable.

sudo minicom -c on -D /dev/ttyUSB0 -b 921600

Default serial port: /dev/ttyUSB0 (FTDI adapter) or /dev/ttyACM0 (native USB). Serial settings: 921600 baud, 8N1, no flow control.

5. Boot Sequence

6. First-Boot Verification

# Login as root (no password on development image)

# 1. Check TEE device exists
ls /dev/tee0 /dev/teepriv0
Expected output: 
/dev/tee0  /dev/teepriv0
# 2. Verify tee-supplicant is running
systemctl status optee.service
Expected output: 
● optee.service - OP-TEE supplicant
     Active: active (running) since ...
# 3. Verify PKCS#11 TA is installed
ls /usr/lib/optee_armtz/fd02c9da-306c-48c7-a49c-bbd827ae86ee.ta
Expected output: 
/usr/lib/optee_armtz/fd02c9da-306c-48c7-a49c-bbd827ae86ee.ta
# 4. Verify PKCS#11 client library
ls /usr/lib/libckteec.so
Expected output: 
/usr/lib/libckteec.so
# 5. Initialize PKCS#11 (first boot only)
#    On a fresh image the TA is not yet provisioned.
#    Run the test menu and select "reset" to initialize:
pkcs-test-menu.py
# 6. List PKCS#11 slots
pkcs11-tool --module /usr/lib/libckteec.so --list-slots
Expected output: 
Available slots:
Slot 0 (0x0): OP-TEE PKCS11 TA - TEE UUID ...
  token label        : test-token
  token manufacturer : Linaro
  token model        : OP-TEE TA
  token flags        : login required, rng, token initialized, PIN initialized
Slot 1 (0x1): OP-TEE PKCS11 TA - TEE UUID ...
  token state:   uninitialized
Slot 2 (0x2): OP-TEE PKCS11 TA - TEE UUID ...
  token state:   uninitialized
