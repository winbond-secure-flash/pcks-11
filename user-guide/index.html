W77Q/T PKCS#11 User Guide

ALPHA RELEASE — This is a pre-production technology preview. APIs, flash layout, and provisioning flows may change without notice. Do not deploy to production systems.

This release provides PKCS#11 secure key and object storage on Winbond W77Q/T secure NOR flash for the Renesas R-Car V4H Sparrow Hawk board. Keys and certificates are generated and stored entirely inside OP-TEE Secure World — they never appear in Normal World (Linux) memory.

The underlying storage uses the QLIB authenticated session protocol to protect data at rest on the W77Q/T flash chip. All cryptographic operations are performed within the ARM TrustZone secure environment.

Known Limitations

  1. Development keys in use — sample keys are hardcoded; must be replaced for production.
  2. LittleFS geometry compatibility — storage now uses the LittleFS backend. Changing block geometry (for example W77Q_LFS_BLOCK_SIZE) requires reformatting PKCS#11 storage; existing data is not layout-compatible across geometry changes.
